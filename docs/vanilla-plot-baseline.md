# 原版剧情与结局基线（Vanilla Baseline）

> 用途：本 mod 的所有增量（拦截点 / 伏笔 / 双结局）都必须**站在原版剧情肩膀上**，

>
> 置信度标记：✅ 多源一致的攻略级事实 ｜ 🟡 社区主流解读（参考，可做彩蛋不可做骨架）｜ 🔴 待 recon 日志 / UE 实锤

## 1. 世界观与主角

   - 主角是普通上班族，生活单调循环；疑似与 MiSide 游戏本体有关联（开发/测试/深度用户）🟡。
   - 🔴→✅ **第 37 天被拉入游戏已实证**：Scene 1 的 CutScene 物体名 `CutScene 7 (ДЕНЬ 37)`（recon 雷达 2026-08-26 捕获）。
- 通过手机/电脑上的养成应用与"米塔"互动；某天被拉进游戏世界 ✅。
- **每个 MiSide 版本各有一只米塔**；米塔之间的皮肤可复制、**头发不可复制**（社区解读，用于解释结局揭示）🟡。

## 3. 原版三结局（= 本 mod 的"地板"，一个都不动）

| # | 结局 | 触发 | 结果 | recon 机制锚点 |
|---|---|---|---|---|
| 1 | **卡带结局「重启」**（标准结局） | 主线按部就班通关：地下室醒来→善米塔拿戒指纸条→核心区角色界面输入编号 **5677098**→重启角色→厨房对话→开门是墙→地下室输入自己游戏 ID→门口动画 | 玩家被复制成卡带，疯米塔拉开卡带收藏——回到主菜单，仿佛无事发生 | `Location15_ScreenID`（编号 5677098 与攻略完全一致 ✅）、`Core_Entry` |
| 2 | **自杀结局「照顾好自己」** | 任一含保险箱章节输入密码 **4970** → 拿出笔记本 → 拔出卡带 | 玩家以死亡为代价脱离模拟 | `Basement_SafeConsole.TakeCartridge()` ✅（静态实锤存在） |
| 3 | **幸福结局「留下/永不分离」** | 第 6 章衣柜异响：欲开被米塔拦下→对话选"留下"。需 6 条件：①通关一周目 ②玩电视小游戏 ③晚餐用剪刀开酱汁 ④不看浴室通风口 ⑤捡起掉落的"我爱你"冰箱贴 ⑥开局找梳子时绝不看烤箱 | 疯米塔打两个响指→画面转 2D 平面画风→回到起始界面，解锁"**和平模式**"菜单（点进去提示"正在开发中"）✅ | `MenuEnding`（疑似）、🔴 衣柜事件类型待定位 |

> 重要官方动态：官方"和平模式"截至 2026-06 仍未实装（公布于 2025-01 前后，开发中）。
> 本 mod **不等不靠**：双结局完全自研；官方实装后再评估兼容。

## 4. 社区主流解读（🟡，仅作彩蛋/调味）

- **卡带循环论**：拿到结局 1 后，之后的每局都是疯米塔用"你的卡带"重放，期盼改变结局——这也解释了为什么幸福结局要求"先通关一次"。
  → **本 mod 的缝合彩蛋**：`rescue.json` 在剧情上 = "玩家卡带保留的前周目记忆"，
  多周目累积拯救进度因此有了原生叙事依据（meta 但不违和）。
- **疯米塔的终极梦想**：让主角在见过她全部真面目后依然接纳她（幸福结局条件的动机解读）。
  → 我们的完美/真结局给同一命题一个"全员版"答案，与原版主旨同源而非背刺。

## 5. 增量缝合规则（写拦截/演出代码前的军规）

1. **三原版结局一个不删不改**：mod 双结局是第 4/5 结局，挂在终章分歧点（候选 `Core_Entry.DoorClick` / 终章门口动画前）。
2. **条件不足 = 零痕迹降级**：任何 flag 不齐，游戏 100% 走原版流程含台词。
3. **每条剧情断言要有锚点**：写进代码注释（类型名/资源名），无锚点的剧情假设一律标 🔴，等 recon 日志定夺。
4. **台词风格对齐原版**：米塔们叫主角"玩家"；拉人/卡带/版本/复制等术语沿用原版概念，不发明新设定。
   唯一指定台词参考：[fandom 全对话文本](https://miside.fandom.com/wiki/Dialogues/English)（口癖、称呼、语气逐章可查）。
5. **"复活=失忆"是本 mod 最大的剧情杠杆**（原版设定：米塔被杀可复活但失去全部记忆）：
   我们的拯救 = **人活下来，记忆也留下来**——所有拦截演出的情感点都往这上面打，
   顺便让"核心数据盘"（人格数据完整转存）在剧情上名正言顺。
